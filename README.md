# Red Majestic

Red Majestic es una aplicación de consola desarrollada en C# como prueba de concepto académica para la consulta de movimientos transaccionales asociados a tarjetas de crédito.

## Tecnologías

- C#
- .NET 10
- Visual Studio
- Git
- GitHub
- GitHub Copilot

## Tarjetas soportadas

La primera versión contempla:

- Visa
- Mastercard
- Diners Club

## Objetivo académico

El proyecto busca aplicar conceptos fundamentales de programación en C#, incluyendo:

- variables;
- cadenas;
- funciones;
- parámetros;
- valores booleanos;
- constantes;
- estructuras condicionales;
- `switch`;
- `for`;
- `while`;
- `do-while`;
- `foreach`;
- vectores;
- listas;
- diccionarios.

## Documentación

La documentación principal del proyecto se encuentra en:

## Flujo de desarrollo

El flujo general del proyecto es:

`Requirement → Issue → Branch → Implementación → Commit → Push → Pull Request → Revisión → Merge`

Las nuevas funcionalidades no deben desarrollarse directamente sobre `main`.
